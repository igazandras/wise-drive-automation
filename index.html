Wise Drive Automation - Privacy Policy

This is an internal, personal-use automation tool built for Next Adventure Kft. (igazandras@gmail.com). It is not distributed to the public.

Purpose: automatically copies monthly bank statement PDFs (from Wise) that the account owner has already downloaded, into a designated folder in that same Google Drive account.

Data accessed: only files created by this tool in the user's own Google Drive, via the drive.file OAuth scope. No other Drive content is accessed, and no data is shared with or transmitted to any third party.
